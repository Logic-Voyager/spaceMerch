  <h1>🚀 Enigma - Space-Themed eCommerce</h1>
  <p><strong>Built during <em>SpaceCon</em></strong>, Enigma is an immersive space-themed eCommerce platform designed to make astronomy accessible, engaging, and fun through fictional products and thoughtful storytelling.</p>

  <h2>🧠 Inspiration</h2>
  <p>The universe is full of wonder - and so is learning to build in a time crunch. I created <strong>Enigma</strong> to combine my interest in astronomy with web development during the SpaceCon hackathon.</p>

  <h2>🛠️ Tech Stack</h2>
  <ul>
    <li><strong>Frontend:</strong> HTML, CSS, and vanilla JavaScript (ES6)</li>
    <li><strong>Forms & Hosting:</strong> Netlify Forms and Netlify-ready static hosting</li>
    <li><strong>Icons:</strong> Font Awesome</li>
    <li><strong>Version Control:</strong> Git and GitHub</li>
  </ul>

  <h2>🧩 Features</h2>
  <ul>
    <li>🛒 Browse fictional space-themed merchandise</li>
    <li>🔎 Open products in a dedicated product-detail view</li>
    <li>🧺 Add products to a persistent browser-based cart</li>
    <li>🔢 Update quantities, clear the cart, and review the order total</li>
    <li>🔔 See an in-page notification when an item is added to the cart</li>
    <li>💳 Review a demo checkout and payment form</li>
    <li>📖 Read astronomy articles about nebulae, stargazing, spacesuits, and Earth from orbit</li>
    <li>📱 Responsive layouts for desktop, tablet, and mobile</li>
    <li>⚙️ Responsive header with navigation and mobile menu</li>
    <li>🌟 Space-themed hero sections, promotions, and editorial page headers</li>
    <li>📨 Newsletter and contact forms prepared for Netlify Forms</li>
  </ul>

  <h2>📁 Pages</h2>
  <ul>
    <li><strong>Home:</strong> collections, promotions, and newsletter signup</li>
    <li><strong>Shop:</strong> available space merchandise</li>
    <li><strong>Product:</strong> details and add-to-cart action</li>
    <li><strong>Cart:</strong> saved products, quantities, and total</li>
    <li><strong>Payment:</strong> demo delivery and payment experience</li>
    <li><strong>Blog:</strong> astronomy journal and field notes</li>
    <li><strong>About:</strong> Enigma's origin story and mission</li>
    <li><strong>Contact:</strong> support information, FAQs, and contact form</li>
  </ul>

  <h2>▶️ Run Locally</h2>
  <p>No build tools or package installation are required. Open the project folder in VS Code and start a static server, for example:</p>
  <pre><code>python -m http.server 8000</code></pre>
  <p>Then visit <code>http://localhost:8000</code>. Opening <code>index.html</code> directly also works for basic browsing.</p>
